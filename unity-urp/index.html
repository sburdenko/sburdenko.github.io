The URP Asset is the global quality contract. The Renderer Data asset defines how the frame is built. Quality levels can point at different URP Assets, so mobile and desktop do not need the same settings.

Migration order

Commit or back up → install URP → create URP Asset and Renderer → assign it in Graphics/Quality → run Render Pipeline Converter → inspect custom shaders and every important scene.

Why source control first

Material and asset conversion changes files and has no single Undo button. A clean commit is the rollback plan.

Forward+

Spatially clusters lights, keeps MSAA and camera stacking, and is the path required by the GPU Resident Drawer.

Deferred

Handles many opaque lit pixels well, but spends memory on G-buffers, does not support MSAA, and still renders transparents forward.

CH.03 // PROBES, APV & REFLECTIONS

Baked worlds still need moving objects to belong

Lightmaps illuminate static surfaces. Light Probes and APVs give dynamic objects sampled indirect light. Reflection Probes provide a local cubemap for shiny surfaces. These solve different missing data.

Lightmaps

Best data for static surfaces. Cheap at runtime, but baked direct light loses real-time specular response.

Light Probes / APV

Spherical-harmonic lighting sampled in space and interpolated for moving renderers.

Reflection Probes

Local cubemaps for environment reflections. Use the smallest resolution that survives the closest camera view.

    Q01Why can increasing Shadow Distance make nearby shadows worse?

    The same shadow-map resolution covers a larger world area, so fewer texels describe each nearby meter. Use the shortest acceptable distance, then place cascade splits around visible shadow casters.

    Q02Why does a shadowed Point Light cost more than a Spot Light?

    A Point Light emits in every direction, so Unity renders six shadow maps for its cubemap. A Spot Light needs one.

    Q03What is the main Render Graph idea?

    A pass explicitly declares the resources it reads and writes. The graph can then schedule work, calculate resource lifetimes, reuse memory and remove unused passes safely.

    Q04Frame Debugger or Profiler?

    Frame Debugger answers “what was drawn, in what order, and with which state?” Profiler answers “where did CPU/GPU time and memory go?” A rendering investigation commonly needs both.
