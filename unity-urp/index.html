INTERACTIVE · HOW MSAA WORKS

One pixel, several coverage tests

Book p. 36

A pixel is still resolved to one final color. MSAA places several sample points inside it, asks which samples the triangle covers, stores coverage/depth per sample, then averages them at resolve.

SAMPLES PER PIXEL
WHAT IS ALIASING?
RASTERIZER · COVERAGE MASK4× MSAA

1 · COVERAGE

Rasterization tests every sample position against the triangle edge.

2 · STORE

Color, depth and stencil can carry multiple samples for edge pixels.

3 · RESOLVE

Covered and uncovered samples are averaged into one display pixel.

Where MSAA wins

Sharp geometric edges, stable VR images and little temporal ghosting. Forward and Forward+ support it in URP.

What you pay

More multisampled color/depth memory, bandwidth and resolve work. Deferred does not support MSAA in URP.

The memory number below estimates RGBA8 color + 32-bit depth at 1920×1080. Real cost depends on the GPU, formats, tile memory and enabled buffers. Fragment shading is not automatically multiplied by the sample count unless per-sample shading is used.

Migration order

Commit or back up → install URP → create URP Asset and Renderer → assign it in Graphics/Quality → run Render Pipeline Converter → inspect custom shaders and every important scene.

Why source control first

Material and asset conversion changes files and has no single Undo button. A clean commit is the rollback plan.

Forward+

Spatially clusters lights, keeps MSAA and camera stacking, and is the path required by the GPU Resident Drawer.

Deferred

Handles many opaque lit pixels well, but spends memory on G-buffers, does not support MSAA, and still renders transparents forward.

CH.03 // PROBES, APV & REFLECTIONS

Baked worlds still need moving objects to belong

Lightmaps illuminate static surfaces. Light Probes and APVs give dynamic objects sampled indirect light. Reflection Probes provide a local cubemap for shiny surfaces. These solve different missing data.

Lightmaps

Best data for static surfaces. Cheap at runtime, but baked direct light loses real-time specular response.

Light Probes / APV

Spherical-harmonic lighting sampled in space and interpolated for moving renderers.

Reflection Probes

Local cubemaps for environment reflections. Use the smallest resolution that survives the closest camera view.

CH.04 // SHADERS

A shader is a contract with the pipeline

URP shader code uses HLSL and URP includes. A useful shader is more than its visible color: passes and tags tell URP when it participates in depth, lighting and shadows.

INTERACTIVE · SHADER ANATOMY

Book pp. 93–104
LIT · SHADOWS ON

Lit uses physically based lighting and supports more material features. Simple Lit trades some fidelity for a cheaper shading model.

Shader Graph is the artist-facing authoring tool. Handwritten HLSL remains useful when you need exact control, reusable includes, or a custom Renderer Feature.

CH.05 // RENDERER FEATURES & RENDER GRAPH

The frame is a dependency graph, not a pile of callbacks

Each pass declares what it reads and writes. Render Graph can derive resource lifetimes, reuse transient memory and remove work whose result nobody consumes.
